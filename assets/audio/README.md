# Audio assets & licence notes

**Shipped audio: none.** No copyrighted voices or clips are included.

By default, reactions are spoken with the browser's built-in Web Speech API
(free, no assets, works offline if the device has an offline voice installed).
Punjabi/Urdu voices vary by device; the app falls back to Hindi/English voices.

## Adding your own recordings (recommended for the best comedy)
1. Record the lines yourself (or friends who consent), or use audio you are
   licensed to use (e.g. CC0 / CC-BY - keep attribution below).
2. Save as `<line id>.mp3` (or .ogg/.wav) in this folder, e.g. `thulla_00.mp3`.
   Line ids and texts are in `thulla/voice/lines.py`.
3. Recordings are used automatically in place of speech.
4. Record each file's source and licence in the table below.
